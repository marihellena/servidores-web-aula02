Servidor Local x Servidor Remoto

Servidor local

É utilizado no próprio computador ou em uma rede interna, principalmente para desenvolvimento e testes.

Servidor remoto

É utilizado para hospedar aplicações acessíveis pela Internet.

Ambiente de desenvolvimento

Local onde o programador cria, executa e testa a aplicação sem afetar usuários reais.

Ambiente de produção

Ambiente em que a aplicação é disponibilizada para os usuários finais, exigindo estabilidade, desempenho e segurança.

Exemplo prático

Durante os testes uso XAMPP no computador. Depois publico o sistema em um servidor remoto para acesso pela Internet.
