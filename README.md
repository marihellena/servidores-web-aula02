Resumo da aula
A aula apresenta servidores Web, tipos de servidores, arquitetura, modelo de requisição e resposta, ambientes de desenvolvimento e produção, versionamento com Git, segurança, virtualização, computação em nuvem e Edge Computing.

Arquivos
exercicio1.html — página HTML simples.
exercicio2.html — identificação de cliente, servidor e resposta.
exercicio3.html — diferença entre servidor local/remoto e desenvolvimento/produção.

O que aprendi
Aprendi que o navegador atua como cliente e envia requisições ao servidor, que processa as solicitações e devolve respostas. Também compreendi a diferença entre servidores locais e remotos, a importância do Git para versionamento e os cuidados necessários para publicar aplicações com segurança.
